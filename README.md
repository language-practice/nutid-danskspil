# Nutid – Dansk grammatikspil

A standalone Danish present-tense learning game for A1–A2 learners.

## Activities
1. **Skriv verbet i nutid** – 25 sentences with automatic checking.
2. **Find fejlen** – 10 incorrect sentences.
3. **Tal sammen to og to** – 15 conversation questions.
4. **Skriv om din hverdag** – writing practice and checklist.

Students can switch freely between tasks. Each task has an independent **Slet alle svar i denne opgave** reset button. Progress is stored in the browser with localStorage.

## Play
Open `index.html` or visit the GitHub Pages website.

No build tools or dependencies are needed.
